## 1. Bernoulli 与 log loss

### 1.1 Bernoulli 分布

```text
Y ~ Bernoulli(p)
```

这表示目标变量 Y 只有两种可能：1 或 0。p 表示 Y=1 的概率，1-p 表示 Y=0 的概率。二分类问题本质上就是在估计这个 p。

### 1.2 单样本 likelihood

```text
L(p; y) = p^y * (1-p)^(1-y)
```

当 y=1 时，这个式子变成 p；当 y=0 时，这个式子变成 1-p。也就是说，模型给真实类别分配的概率越高，likelihood 越大。

### 1.3 单样本负对数似然 / log loss

```text
loss = -[ y*log(p) + (1-y)*log(1-p) ]
```

log loss 是 Bernoulli likelihood 取负对数后得到的。模型给真实类别的概率越低，loss 越大。尤其是模型错得很自信时，log loss 会给出很大的惩罚。

这张图的横轴是预测为正类的概率 p，纵轴是 loss value。图中比较了 squared error 和 log loss，并分别展示了真实标签 y=1 和 y=0 的情况。

当模型错得很自信时，log loss 的惩罚更重。例如真实 y=1 但模型给 p 接近 0，或者真实 y=0 但模型给 p 接近 1 时，log loss 会迅速变大。

二分类里错得很自信需要被重罚，因为这说明模型不仅预测错了，而且还非常确信错误答案。对于概率模型来说，这种错误比一般错误更严重。

log loss 不是凭空指定的，而是来自 Bernoulli likelihood。既然我们把输出解释为概率，那么使用 Bernoulli likelihood 的负对数作为损失函数就很自然。

## 5. 业务场景：疾病初筛

如果是疾病初筛，我最在意 recall。因为漏掉真正有病的人，也就是 FN，代价通常很高。

在这个场景下，我宁愿多筛出一些可疑样本，再通过后续检查确认，也不希望把真正有风险的人漏掉。

如果给业务方推荐阈值，我会选择一个 recall 较高，同时 precision 和 F1 不至于太差的阈值。也就是说，阈值选择不是固定 0.5，而是要结合业务风险来定。
