# Week 15: Summary

## 1. Logistic Regression is not just Linear Regression + sigmoid
The key difference is the probabilistic interpretation and the Bernoulli likelihood.

## 2. Sigmoid, Bernoulli Likelihood, Log Loss
- Sigmoid maps linear output to probability.
- Bernoulli likelihood measures probability of observed labels.
- Log loss is the negative log of Bernoulli likelihood.

## 3. Accuracy is not enough
Accuracy ignores class imbalance and doesn't distinguish error types.

## 4. L1 vs L2
- L1: sparsity, feature selection.
- L2: stability, handles correlation.

## 5. Logistic Regression as a strong baseline
- Outputs interpretable probabilities.
- Coefficients show variable direction and magnitude.
- Fast, stable, and works with regularization.
